# RJC Dermaglow — Muse version

A website sample for **RJC Dermaglow and Aesthetic Medical Clinic** (Manila), built by Muse / Alexandra from the clinic's public Facebook page: https://www.facebook.com/dermaglowmd/

This version applies the design patterns used in this repo's other samples (real photography, serif display type with italic accents, numbered treatment cards, scroll reveal, mobile contact dock) while keeping only the clinic's verified details — address, hours, phone/WhatsApp, email, and the treatments actually featured on its Facebook page. No prices, doctors, or treatments were invented.

`index.html` is a single self-contained file (styles, scripts, and images inlined), exported from the hosted version so it can be opened directly or served by GitHub Pages.

Photos: stock photos via Pexels, credited in the page footer.
